# GuestBook ---

# RF1
O serviço deve permitir o usuário criar uma conta

# RF2
O serviço deve criar a página de comentários do usuário

# RF3
O serviço deve deixar usuários comentarem no perfil de outros usuários

# RF4
O serviço deve permitir os usuários se identificarem ao comentar em outros perfis

# RF5
O serviço deve permitir o usuário dono excluir mensagens no seu próprio perfil

# RF6
O serviço deve permitir indexar os comentários em sites de terceiros

# RF7
o sistema deve permitir alteração de senha

# RF8
O sistema deve permitir a estilização da página

# RF9
O sistema deve permitir deixar "likes" em comentários
